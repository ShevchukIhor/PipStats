3. Data & Privacy

PipStats stores all usage statistics locally on your device in an SQLite database. No usage data, personal information, or analytics are transmitted to any external server. When you connect a Solana wallet via Seed Vault or Mobile Wallet Adapter, the App performs read-only queries to public Solana RPC endpoints using your public address. Private keys and seed phrases never leave the secure Seed Vault hardware enclave.

4. Seed Vault & Wallet Connection

The App integrates with Solana Mobile's Seed Vault via Mobile Wallet Adapter (MWA) for transaction signing. You authorize each transaction explicitly through the Seed Vault UI (double-tap on Seeker). The App never has access to your private keys or seed phrase.

5. Third-Party Services

No personal data is sent to these services beyond your public wallet address.

6. SKR Token Tipping

The App includes an optional tip feature using the SKR token. Tips are sent from your wallet to the developer address via Seed Vault signing. Tipping is entirely optional and not required for any App functionality.
